# 每日创作台 · 移动端单文件应用

一个**单文件、无后端、数据存浏览器本地**的移动端创作工作台。宝石蓝主色、圆角卡片、左侧抽屉导航，含 7 个模块，每天自动更新。

> 当前线上版：**https://af273e2275eb2ff35.sh1.agentos-app.net**（手机浏览器打开，可「添加到主屏幕」）

## 七个模块
| 模块 | 内容 |
|------|------|
| 🏠 概览 | 今日焦点 + 数据概览 + 快速入口 |
| 🔤 英语练习 | 每天 10 条，含音标/标签/中文说明/例句；一键唤起「百词斩」「流利说」 |
| 📰 今日热点 | 新华财经 · 证券时报 · 财联社 · 21财经，每天实时更新 |
| 🔥 1688爆款二创 | 每天 10 热门爆款 + 10 最新下单款式，附「改编角度」 |
| 🌏 国际站新款二创 | 阿里巴巴国际站同源结构 |
| 💰 基金 | 参考养基宝，每日 14:00 净流入资金最大榜 |
| 📈 股票 | 参考同花顺，每日 14:00 净流入资金最大榜 |

## 数据从哪来
网页默认读取一个**公开 GitHub Gist**（`index.html` 里的 `GIST_URL`）。
- 有 Gist：右上角「⟳」随时刷新，拉取最新。
- 无 Gist（或读取失败）：自动回退到内置种子数据，页面始终有内容。

每天 **北京时间 8 / 14 / 20 点**，GitHub Actions 跑 `generate.py`：
1. 按你的「赛道关键词」用 AI 生成英语/产品二创内容；
2. 整理今日四大财经热点；
3. 生成基金/股票净流入榜；
4. 组装成网页所需 JSON，推送到公开 Gist。

## 本地预览
直接双击 `index.html` 即可（用浏览器打开）。或起个静态服务：
```bash
python3 -m http.server 8000   # 打开 http://localhost:8000
```

## 想让数据「活」起来，你需要给我 3 样 + 1 样
1. **GitHub Token**（有 `gist` 权限的 PAT）——用来建/写公开 Gist、启用 Actions。
2. **赛道关键词**（逗号分隔，如 `家居好物,宠物用品,解压玩具`）——AI 据此生成产品/英语/热点。
3. **公众号来源**（如你的公众号名/口径）——热点模块署名与风格参考。
4. **（额外）LLM API Key**（OpenAI 兼容，如 DeepSeek/通义/OpenAI）——负责「AI 改写」。
   > 不填也能跑：脚本用规则兜底产出可用内容，但质量和贴合度会下降。

提供后我会：建仓库 → 配 Secrets → 建 Gist 并把地址写进 `index.html` → 重新部署 → 跑一次验证。

## 自己改
- **换主色**：改 `index.html` 顶部 CSS 的 `--primary`。
- **改 Gist 地址**：改 `index.html` 顶部 `var GIST_URL = "..."`。
- **本地试跑生成器**：
  ```bash
  NICHE_KEYWORDS="家居好物,宠物用品" python3 generate.py
  # 生成 data.json 并打印统计；配了 GIST_TOKEN 会直接推送到 Gist
  ```

## 文件
